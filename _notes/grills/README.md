# 요구사항 인터뷰·결정 기록

`grill-me` 스킬이 사용자와의 인터뷰를 통해 정리한 요구사항과 설계 결정을 보관합니다.
구현 전에 무엇을 만들고, 어떤 선택을 했으며, 무엇을 검증해야 하는지 공유하는 문서입니다.

## 담는 내용

- 문제와 목표, 저장소에서 확인한 사실
- 사용자가 확정한 선택과 그 근거
- 제약·가정, 이번 작업의 범위 밖 항목
- 예상 영향, 열린 질문, 수용 기준과 검증 방법

## 작성 규칙

파일명은 [공통 파일명 규칙](../README.md#파일명-규칙)에 따라
`<yymmdd-hhmm>-<topic-slug>.md`로 짓습니다. 예: `260908-1430-search-filter.md`.
접두어는 생성 시각이며 갱신 시 유지합니다. 같은 주제의 인계 문서와 주제 슬러그를
맞추되 생성 시각은 각 문서에서 실제로 확인합니다.

같은 주제의 기록이 있으면 먼저 읽고 갱신합니다. 중요한 결정이 바뀌면 이전 선택과
변경 이유를 남깁니다. 답변하지 않은 질문이나 권장안은 확정된 결정과 구분합니다.

상세 절차와 문서 형식은 [grill-me 스킬](../../.agents/skills/grill-me/SKILL.md)을
따릅니다. 현재 구현 상태와 다음 세션의 할 일은 [handoffs](../handoffs/README.md)에
기록하고, 필요한 결정 문서를 링크합니다.
