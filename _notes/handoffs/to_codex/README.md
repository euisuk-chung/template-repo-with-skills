# Codex에 전달할 지침서

새 Codex 세션에 맡길 구현·리뷰·조사 요청을 보관합니다. 작성한 도구와 관계없이
수신 대상이 Codex인 문서를 여기에 둡니다.

[공통 작성 규칙](../README.md)에 따라 `<yymmdd-hhmm>-<topic-slug>.md`로 작성합니다.
예: `260908-1500-search-filter.md`, `260908-1600-search-filter-review.md`.

요청 목적, 저장소 기준점, 필요한 입력과 환경, 작업 범위, 실행 순서, 검증 방법과
결과물 형식을 적습니다. 이전 세션의 대화·메모리·미커밋 파일을 새 세션이 자동으로
공유한다고 가정하지 않습니다. 필요한 스킬은 중앙 원본 경로로 안내합니다.

새 세션 요청 예시(문서를 실제로 작성한 뒤 사용):

```text
_notes/handoffs/to_codex/260908-1500-search-filter.md를 읽고 그 안의 작업 요청을 수행해줘.
먼저 현재 저장소와 입력 자료가 문서의 기준점에 맞는지 확인해줘.
```
