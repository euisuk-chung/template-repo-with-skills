# 사람에게 전달할 지침서

개발자·리뷰어 등 담당자에게 전달할 구현·리뷰·조사 요청을 보관합니다.
담당자가 이전 대화에 참여하지 않았어도 요청과 완료 조건을 이해할 수 있게 작성합니다.

[공통 작성 규칙](../README.md)에 따라 `<yymmdd-hhmm>-<topic-slug>.md`로 작성합니다.
예: `260908-1500-search-filter.md`, `260908-1600-search-filter-review.md`.

배경, 요청 사항, 대상 파일·변경 범위, 필요한 접근 권한과 환경, 기대 결과물을
설명합니다. 실행 명령에는 작업 디렉터리와 기대 결과를 적고, 에이전트 전용 도구명이나
스킬 호출만으로 수행 방법을 대신하지 않습니다. 기한·담당자는 정해진 경우에만 기록합니다.

전달 요청 예시(문서를 실제로 작성한 뒤 사용):

```text
_notes/handoffs/to_human/260908-1600-search-filter-review.md에 정리한 변경 사항을 리뷰해 주세요.
검토 대상과 확인 항목, 결과물 형식은 문서에 있습니다.
```
