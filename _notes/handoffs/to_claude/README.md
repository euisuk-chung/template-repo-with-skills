# Claude에 전달할 지침서

새 Claude 세션에 맡길 구현·리뷰·조사 요청을 보관합니다. 작성한 도구와 관계없이
수신 대상이 Claude인 문서를 여기에 둡니다.

[공통 작성 규칙](../README.md)에 따라 `<yymmdd-hhmm>-<topic-slug>.md`로 작성합니다.
예: `260908-1500-search-filter.md`, `260908-1600-search-filter-review.md`.

요청 목적, 저장소 기준점, 필요한 입력과 환경, 작업 범위, 실행 순서, 검증 방법과
결과물 형식을 적습니다. 이전 세션의 대화나 특정 도구가 반드시 제공된다고 가정하지
않습니다. 저장소 접근이 없는 환경에서는 지침서가 요구하는 파일도 별도로 전달해야 합니다.

새 세션 요청 예시(문서를 실제로 작성한 뒤 사용):

```text
_notes/handoffs/to_claude/260908-1600-search-filter-review.md를 읽고 리뷰를 수행해줘.
문서에 지정한 검토 범위와 결과물 형식을 따라줘.
```
